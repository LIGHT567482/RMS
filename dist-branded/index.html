Separate branding & packaging for RMS

This dashboard is intentionally separate from the RMS app. Use it to create a standalone branding package for school details, logos, and colors.

School branding package

Enter the school details and download a branded package file. This file can be used to generate a branded RMS distribution with the provided packaging script.

Configuration is stored locally in this browser when you click Save.

Next step

After exporting your branding JSON, use the RMS packaging script from the repository root: 

npm run package:branded -- light-distributor/branding.json

This creates a branded RMS distribution in dist-branded/ and injects the configuration into the build.
