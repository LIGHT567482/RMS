Next step

After exporting your branding JSON, use the RMS packaging script from the repository root: 

npm run package:branded -- light-distributor/branding.json

This creates a fully bundled branded RMS distribution in dist-branded/. The native app will use the configured logo, colors, and productName, and the installed application launches as a normal system app without exposed source code.
